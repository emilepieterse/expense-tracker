# Expense Tracker

A simple expense tracker that runs entirely in the browser. Add, edit, and delete expenses, see your total spending, and get a quick breakdown by category.

## Features

- Add an expense with a description, amount, category, and date
- Edit or delete any existing expense (delete asks for confirmation first)
- Filter the list by category
- Running total of all expenses
- Spending breakdown grouped by category
- Data is saved in the browser's localStorage, so it persists across reloads

## How to run

No build step or dependencies needed, it's just HTML/CSS/JS.

1. Clone the repo
2. Open `index.html` in a browser

or serve it locally:

```
npx serve .
```

## Tech used

- HTML
- CSS
- Vanilla JavaScript
- localStorage for data persistence
